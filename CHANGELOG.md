# Changelog

## [0.1.1] - 2026-05-12

### Added
- New card configuration options: `card_title`, `show_header`, `show_current_time`, `time_format`, `title_color`, `badge_text_color`, `divider_color`, `divider_thickness`, `show_station_title`, and `row_gap`.
- Extended editor UI to support advanced card settings and JSON configuration for `entity_map` and `colors`.
- Added `badge_width`, `destination_width`, `destination_font_size`, `departure_font_size`, and `minutes_font_size` configuration.
- Added documentation for the new configuration options in `README.md`.

### Fixed
- Improved card header rendering and visual styling for both fixed and fluid layouts.
- Removed visual editor support so configuration is merged only through YAML.
